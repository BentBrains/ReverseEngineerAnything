ఒక యాప్‌లో మీకు నచ్చిన ఫీచర్ మీ సొంత ప్రొడక్ట్‌లో కావాలా? దాన్ని REAతో పరిశోధించమని మీ ఏజెంట్‌ను అడగండి. సోర్స్ కోడ్ లేకుండానే యాప్‌ను పరిశీలించి, ఆ ఫీచర్ ఎలా పనిచేస్తుందో వివరించి, రుజువులు చూపించి, మీ ప్రాజెక్ట్ కోసం దాని వెర్షన్‌ను నిర్మించగలదు.

REA మీ ఏజెంట్‌ను నేటివ్ బైనరీలు, JavaScript మరియు Electron యాప్‌లు, .NET అసెంబ్లీలు, వెబ్‌సైట్‌లను పరిశీలించే టూల్స్‌కు కలుపుతుంది. అదే టూల్స్‌ను మీ టెర్మినల్ నుంచి కూడా వాడవచ్చు. విశ్లేషణ లోకల్‌గానే జరుగుతుంది; ఫలితాల్లో ప్రతి నిర్ణయానికి ఆధారమైన రుజువులు, పరిమితులు ఉంటాయి.

సెటప్ REAను మీ ఏజెంట్‌లో నమోదు చేసి, సరిపోయే వర్క్‌ఫ్లో సూచనలను ఇన్‌స్టాల్ చేస్తుంది. నేటివ్ విశ్లేషణ కోసం ఇప్పటికే ఉన్న Hopper, Ghidra లేదా IDA ఇన్‌స్టాలేషన్‌ను వాడవచ్చు; అనుమతి ఇస్తే సెటప్ Hopperను ఐచ్ఛికంగా ఇన్‌స్టాల్ చేయగలదు. స్టాటిక్ JavaScript విశ్లేషణకు ఏ నేటివ్ ఇంజిన్ అవసరం లేదు.

> **[REA వెబ్‌సైట్‌ను సందర్శించండి](https://rea.tools/)** — సెటప్ సూచనలు, చిత్రాలతో కూడిన గైడ్‌లు మరియు నిజమైన కేస్ స్టడీల కోసం.

## త్వరిత ప్రారంభం

Linuxలో, Ghidra, JADX, ఫర్మ్‌వేర్ టూల్ లాంచ్‌లు మరియు స్టాటిక్ JavaScript/Electron
విశ్లేషణకు ప్రాసెస్ యాజమాన్య తనిఖీల కోసం REA `PATH`లో procps-అనుకూల `ps` అవసరం.
పునరుద్ధరణ దశలు `docs/installation.md` లో "Linux owned-process prerequisite"
శీర్షిక కింద ఉన్నాయి.

### మీ ఏజెంట్‌ను సెటప్ చేయండి

Node.js మరియు npm ఇన్‌స్టాల్ అయి ఉంటే, ఇది రన్ చేయండి:

```bash
npx rea-agents setup
```

మీ ఏజెంట్లను ఎంచుకోండి, ప్రతిపాదిత మార్పులను సమీక్షించి ఆమోదించండి. సెటప్ REA MCP
సర్వర్‌ను, సరిపోయే వర్క్‌ఫ్లో సూచనలను జోడిస్తుంది; ఇప్పటికే ఉన్న కాన్ఫిగరేషన్‌ల
బ్యాకప్‌లను ఉంచుతుంది. తర్వాత మీ ఏజెంట్‌ను రీస్టార్ట్ చేయండి.

సెటప్ Claude Code, Codex, Cursor, Gemini CLI, Grok Build మరియు
[ఇతర ఏజెంట్లను](../installation.md#supported-agents) సపోర్ట్ చేస్తుంది. ప్రొవైడర్
కాన్ఫిగరేషన్ మరియు మాన్యువల్ MCP నమోదు కోసం
[ఇన్‌స్టాలేషన్ మరియు సెటప్](../installation.md) చూడండి.

### మీ ఏజెంట్‌ను అడగండి

```text
Notes యాప్‌లో సెర్చ్ ఎలా పనిచేస్తుందో అర్థం చేసుకో, రుజువులు చూపించు, నా
ప్రాజెక్ట్ కోసం అలాంటి ఫీచర్‌ను నిర్మించు.
```

Notes స్థానంలో మీ లక్ష్య యాప్‌ను, మీరు అర్థం చేసుకోవాలనుకునే ఫీచర్‌ను పెట్టండి.

### టెర్మినల్‌ను వాడండి

విప్పగా ఉన్న JavaScript/Electron యాప్ డైరెక్టరీని లేదా ASAR ఫైల్‌ను పరిశీలించండి:

```bash
npx -y rea-agents@latest analyze-javascript-application /absolute/path/to/app --json
```

ఫలితంలో మాడ్యూల్స్, ఇంపోర్ట్‌లు, Electron హద్దులు మరియు వాటి రుజువులు ఉంటాయి. పాత్
స్థానంలో మీ లక్ష్యాన్ని పెట్టండి — ఉదాహరణకు Windowsలో `"D:/apps/example"`.

సాధారణ వాడకం కోసం `rea` కమాండ్‌ను ఇన్‌స్టాల్ చేయడానికి:

```bash
npm install --global rea-agents
rea --help
```

నేటివ్ విశ్లేషణ కోసం ముందుగా ఒక ప్రొవైడర్‌ను కాన్ఫిగర్ చేయండి. నేటివ్ కమాండ్లు,
ప్రొవైడర్ ఎంపిక, స్నాప్‌షాట్‌లు మరియు స్క్రిప్టింగ్ కోసం
[CLI మరియు Evidence గైడ్](../cli.md) చూడండి.

### REA అప్‌డేట్

REA వేగంగా మారుతుంది; కొత్త రిలీజ్‌లలో తరచుగా బగ్ ఫిక్స్‌లు ఉంటాయి. మీ
ఇన్‌స్టాలేషన్‌ను అప్ టు డేట్‌గా ఉంచండి.

`npm install --global` లేదా `bun add --global` తో ఇన్‌స్టాల్ చేసిన CLI కోసం:

```bash
rea update
```

Bun గ్లోబల్ అప్‌డేట్‌లకు Bun 1.2.17 లేదా కొత్తది అవసరం. పాత Bun రిలీజ్ ఉంటే,
`rea update` రన్ చేయడానికి ముందు Bunను మాన్యువల్‌గా అప్‌గ్రేడ్ చేయండి.

మీ ఏజెంట్ నమోదులు, స్కిల్‌ను రిఫ్రెష్ చేయడానికి అప్‌డేట్ చూపించే సెటప్
కమాండ్‌ను రన్ చేయండి.

మీరు `npx` వాడుతుంటే, మీ ఏజెంట్ సెటప్‌ను ఇలా అప్‌డేట్ చేయండి:

```bash
npx rea-agents@latest setup
```

సెటప్ మార్పులను సమీక్షించి, మీ ఏజెంట్‌ను రీస్టార్ట్ చేయండి. వన్-ఆఫ్ CLI కమాండ్ల
కోసం `npx rea-agents@latest` తర్వాత కమాండ్ రాయండి. Bun ఉంటే
`npx rea-agents@latest` స్థానంలో `bunx rea-agents@latest` వాడండి.

## REA ఎలా పనిచేస్తుంది

మీ ఏజెంట్ MCP ద్వారా REAను కాల్ చేసి లక్ష్యాన్ని పరిశీలించి, సంబంధిత కోడ్‌ను
ట్రేస్ చేస్తుంది. REA ఫలితాలను వాటి రుజువులతో పాటు అందిస్తుంది. వాటితో ఏజెంట్
ఫాలో-అప్ ప్రశ్నలు అడగగలదు, ప్రవర్తనను వివరించగలదు, లేదా ఇంప్లిమెంటేషన్ రాసి
పరీక్షించగలదు. CLI కమాండ్లు అదే వర్క్‌ఫ్లోలను వాడతాయి.

## ఏమి విశ్లేషించవచ్చు

REAకి Node.js 22.x (>=22.19), 24.x (>=24.11), లేదా 26+, మరియు npm అవసరం.
అదనపు టూల్స్, హోస్ట్ సపోర్ట్ లక్ష్యం మీద ఆధారపడతాయి:

| లక్ష్యం                 | REA ఏమి అందిస్తుంది                                                        | అవసరాలు మరియు గైడ్                                                                                                            |
| --------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |

ఆఫ్‌లైన్ నేటివ్-బైనరీ పరిశీలన కోసం, వినియోగదారు అందించే GNU objdump మరియు

చూడండి. REA ఏ ప్రొవైడర్‌ను ఇన్‌స్టాల్ చేయదు, అప్‌డేట్ చేయదు.

[పుల్ రిక్వెస్ట్](https://github.com/morluto/rea/pulls)లో పంచుకోండి — లక్ష్యం, మీ
ప్రశ్న, REA ఎలా సహాయపడింది, మీరు ఏమి కనుగొన్నారో చెప్పండి.

## తరచుగా అడిగే ప్రశ్నలు

<details>
<summary><strong>REAను ఏ ఏజెంట్లు వాడగలవు?</strong></summary>

లోకల్ MCP సర్వర్‌లను సపోర్ట్ చేసే ఏ ఏజెంట్ అయినా. సెటప్
[సపోర్ట్ చేసే ఏజెంట్లను](../installation.md#supported-agents) కాన్ఫిగర్ చేస్తుంది; ఇతర
క్లయింట్లు [మాన్యువల్ MCP నమోదు](../installation.md#mcp-registry) వాడవచ్చు.

</details>

<details>
<summary><strong>Hopper, Ghidra లేదా IDA అవసరమా?</strong></summary>

డీప్ నేటివ్ విశ్లేషణ వాటిలో ఒకటి వాడుతుంది. స్టాటిక్ JavaScript మరియు .NET
పరిశీలన ఏ నేటివ్ విశ్లేషణ ఇంజిన్ లేకుండా పనిచేస్తుంది. సెటప్ అనుమతి తర్వాత
Hopperను ఇన్‌స్టాల్ చేయగలదు; Ghidra మరియు IDA మీ ఇప్పటికే ఉన్న ఇన్‌స్టాలేషన్లను
వాడతాయి. [ప్రొవైడర్ సెటప్](../installation.md#hopper) చూడండి.

</details>

<details>
<summary><strong>ముందుగా Hopperను స్టార్ట్ చేయాలా?</strong></summary>

REAకి అవసరమైనప్పుడు అదే Hopperను స్టార్ట్ చేస్తుంది. macOSలో, మొదటి రన్‌లో demo
మోడ్ ఎంచుకోమని లేదా మీ లైసెన్స్ యాక్టివేట్ చేయమని డైలాగ్ రావచ్చు. మొదటి CLI/MCP
ఆపరేషన్ లేదా పర్యవేక్షణ లేని జాబ్ ముందు, అదే యూజర్ సెషన్‌లో ఆ ప్రాంప్ట్‌ను పూర్తి
చేయండి. అవసరమైతే Hopperను మాన్యువల్‌గా తెరవండి.
[Hopper స్టార్టప్ మరియు ట్రబుల్‌షూటింగ్](../installation.md#launcher-paths-and-troubleshooting)
చూడండి.

</details>

<details>
<summary><strong>skills.sh నుంచి స్కిల్‌ను ఇన్‌స్టాల్ చేస్తే ఏమవుతుంది?</strong></summary>

స్కిల్ మీ ఏజెంట్‌కి పరిశోధన సూచనలను అందిస్తుంది. REA MCP సర్వర్‌ను నమోదు
చేయడానికి, సరిపోయే సూచనలను ఇన్‌స్టాల్ చేయడానికి `npx rea-agents setup` వాడి,
తర్వాత మీ ఏజెంట్‌ను రీస్టార్ట్ చేయండి.
[స్కిల్ మాత్రమే ఇన్‌స్టాలేషన్](../installation.md#skill-only-installation) చూడండి.

</details>

<details>
<summary><strong>REA ఏ కోడ్‌ను ఇస్తుంది?</strong></summary>

నేటివ్ విశ్లేషణ సూడోకోడ్ మరియు అసెంబ్లీని ఇస్తుంది. JavaScript/Electron విశ్లేషణ
మాడ్యూల్స్‌ను, వాటి సంబంధాలను తిరిగి పొందుతుంది. ఈ ఫలితాలతో మీ ఏజెంట్ ఇంప్లిమెంటేషన్
రాసి పరీక్షిస్తుంది; [కేస్ స్టడీలు](#కేస్-స్టడీలు) పూర్తి ఉదాహరణలు ఇస్తాయి.

</details>

<details>
<summary><strong>REA నా యాప్‌ను అప్‌లోడ్ చేస్తుందా?</strong></summary>

REA లక్ష్యాలను లోకల్‌గా విశ్లేషిస్తుంది. టూల్ ఫలితాలు మీ ఏజెంట్‌కి చేరతాయి; దాని
మోడల్ ప్రొవైడర్‌కి స్వంత డేటా పాలసీ ఉంటుంది.

</details>

<details>
<summary><strong>బగ్ ఎదురైతే ఏమి చేయాలి?</strong></summary>

ముందుగా అప్‌డేట్ చేయండి; తాజా రిలీజ్ దాన్ని ఇప్పటికే ఫిక్స్ చేసి ఉండొచ్చు.

`npm install --global` లేదా `bun add --global` తో ఇన్‌స్టాల్ చేసిన CLI కోసం:

```bash
rea update
```

`npx` ద్వారా ఏజెంట్ సెటప్ కోసం:

```bash
npx rea-agents@latest setup
```

మీరు ఏజెంట్ వాడుతుంటే, [సెటప్ రిఫ్రెష్](#rea-అప్‌డేట్) పూర్తి చేసి దాన్ని
రీస్టార్ట్ చేయండి. అదే పనిని మళ్లీ ప్రయత్నించండి. సమస్య కొనసాగితే, మీ REA
వెర్షన్, లక్ష్య రకం, రీప్రొడ్యూస్ దశలు మరియు ఎర్రర్ అవుట్‌పుట్‌తో
[ఒక ఇష్యూ తెరవండి](https://github.com/morluto/rea/issues).

</details>

## డాక్యుమెంటేషన్

వెబ్‌సైట్‌లోని [ఉదాహరణలతో కూడిన గైడ్‌లతో](https://rea.tools/guides/) ప్రారంభించండి.
ఖచ్చితమైన ఆప్షన్లు, ముందస్తు అవసరాలు మరియు ఫలిత కాంట్రాక్టుల కోసం:

- [ఇన్‌స్టాలేషన్ మరియు సెటప్](../installation.md): ఏజెంట్ నమోదు, ప్రొవైడర్ కాన్ఫిగరేషన్, అప్‌డేట్‌లు మరియు అన్‌ఇన్‌స్టాల్.
- [రెడీనెస్ మరియు ట్రబుల్‌షూటింగ్](../installation.md#check-readiness-for-your-task): ఒక ఏజెంట్‌ను లేదా విశ్లేషణ ఇంజిన్‌ను డయాగ్నోస్ చేయండి.
- [CLI మరియు Evidence](../cli.md): కమాండ్లు, ప్రొవైడర్ ఎంపిక, స్నాప్‌షాట్‌లు, ఇంపోర్ట్/ఎక్స్‌పోర్ట్ మరియు ఎగ్జిట్ స్టేటస్‌లు.
- [MCP కాంట్రాక్టులు](../mcp-contracts.md) మరియు [ఏజెంట్ ప్రాంప్ట్‌లు](../mcp-prompts.md): టూల్ ఫలితాలు, సెషన్లు మరియు మార్గదర్శక పరిశోధనలు.
- [టూల్ కాటలాగ్](../mcp-contracts.md#generated-catalog): టూల్స్, ప్రొవైడర్లు మరియు CLI కమాండ్ల జనరేటెడ్ జాబితా.
- [రోడ్‌మ్యాప్](../roadmap.md): ప్లాన్ చేసిన పని మరియు సామర్థ్య ట్రాకర్లు.

భద్రతా లోపాలను [SECURITY.md](../../SECURITY.md) ద్వారా నివేదించండి.
